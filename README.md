# Lego Analysis Dashboard

## overview

an interactive lego data analysis dashboard built with power bi to explore lego sets, themes, age ranges, prices, pieces, and yearly set production.

## key metrics

- total sets: 4,385
- average pieces: 411
- average price: $45

## dashboard features

- lego sets exploration table
- theme group filter
- theme filter
- age range filter
- price range filter
- total sets by theme
- total sets by age range
- price by age range
- set count by theme group
- number of sets by year
- selected set details

## highlighted analysis

- city is the largest displayed theme with 445 sets.
- star wars follows with 388 sets.
- the 5 to 9 age range represents the largest share of sets at 76.12%.
- the 5 to 9 age range also has the highest total price at approximately $114k.
- the dashboard shows the growth in the number of lego sets across different years.
- the razor crest is highlighted as a selected set with a price of $600, 6,187 pieces, and an age range of 20+ years.
